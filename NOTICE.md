# Note di attribuzione

Il codice in `spacedata/` organizza uno snapshot. I file in `data/` restano sotto la licenza della fonte indicata in `data/manifest.json`. Questo repository non li ri-licenzia.

| Codice | Fonte | Uso |
| --- | --- | --- |
| `celestrak-attribution` | [CelesTrak](https://celestrak.org/) | Dati pubblicati per uso libero, con attribuzione a CelesTrak. Le effemeridi pubbliche provengono dal catalogo della 18th Space Defense Squadron. |
| `cc-by-sa-4.0` | [SatNOGS DB e Network](https://satnogs.org/) | Il progetto distribuisce questi dati sotto Creative Commons Attribution-ShareAlike 4.0. Il software SatNOGS è AGPL-3.0 e non è incluso. |
| `us-gov-public-domain` | NOAA Space Weather Prediction Center | Opera del governo degli Stati Uniti. |
| `copernicus-catalog-metadata` | Copernicus Data Space Ecosystem | Solo metadati di collezione. Il campo `license` di ogni collezione va letto: Sentinel e le contributing mission non hanno gli stessi termini. I granuli non sono nello snapshot. |
| `nasa-pds` | NASA Planetary Data System | Metadati dei bundle. Un prodotto si cita con il suo LID. |

Le coordinate delle stazioni SatNOGS sono quelle pubblicate dall'operatore insieme al passaggio. Il nickname dell'operatore e il revisore non sono copiati. I frame demodulati restano agli URL originali.
